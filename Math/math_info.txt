1. SOMATORIOS, PA E PG
--------------------------------------------------
Soma de 1 ate N:         N * (N + 1) / 2
Soma dos N primeiros impares (1 + 3 + ...):  N^2
Soma dos quadrados (1^2 + ... + N^2):  N * (N + 1) * (2*N + 1) / 6
Soma de potencias de 2 (1 + 2 + ... + 2^N):  2^(N + 1) - 1

PA (Progressao Aritmetica):
  Termo n:  a_n = a_1 + (n - 1) * r
  Soma:     S_n = (a_1 + a_n) * n / 2

PG (Progressao Geometrica):
  Termo n:  a_n = a_1 * q^(n - 1)
  Soma:     S_n = a_1 * (q^n - 1) / (q - 1)   (q != 1)
  Infinita: S   = a_1 / (1 - q)               (|q| < 1)


2. CONTAGEM E MULTIPLOS
--------------------------------------------------
Quantos multiplos de K existem em [L, R] (L >= 1):
  (R / K) - ((L - 1) / K)

Qtd de pares distintos entre N elementos:   N * (N - 1) / 2
Qtd de subconjuntos de N elementos:         2^N

Distribuir N itens iguais em K caixas (Stars and Bars):
  - Pode caixa vazia:       C(N + K - 1, K - 1)
  - Minimo 1 por caixa:     C(N - 1, K - 1)

Inclusao-Exclusao:
  2 conj: |A u B| = |A| + |B| - |A n B|
  3 conj: |A u B u C| = |A| + |B| + |C| - |A n B| - |A n C| - |B n C| + |A n B n C|


3. LOGARITMOS
--------------------------------------------------
log(a * b) = log(a) + log(b)
log(a / b) = log(a) - log(b)
log(a^k)   = k * log(a)
Mudanca de base: log_b(a) = log(a) / log(b)
Qtd de digitos de N na base 10: floor(log10(N)) + 1


4. LIMITES E POTENCIAS DE 2
--------------------------------------------------
2^10 = 1.024             (~10^3)
2^20 = 1.048.576         (~10^6)
2^30 = 1.073.741.824     (~10^9)
INT_MAX   = 2^31 - 1     (~2.14 * 10^9)
LLONG_MAX = 2^63 - 1     (~9.22 * 10^18)
